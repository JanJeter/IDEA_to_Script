# Idea2Screenplay V1 UX 设计简报

> 状态：已确认（2026-08-08）  
> 范围：信息架构、关键用户流程、低保真桌面与移动端线框  
> 实现：本文件不包含代码实现

## 1. Feature Summary

Idea2Screenplay V1 是一个无需登录即可体验的中文短剧共创产品，核心用户是短剧与短视频创作者。用户可以输入一句原创创意，或粘贴网文梗概与章节素材，依次审阅故事内核、人物、空间、情节节拍、分场和完整剧本，最后导出可继续修改的初稿。

产品采用混合演示模式。每位访客可以立即浏览完整示例，每台设备每天可以进行一次真实 AI 生成。浏览器最多保存 5 个匿名项目，项目保留 7 天；完整示例固定显示且不可删除。

## 2. Primary User Action

最重要的用户动作是：

> 提交创意或改编素材，并在每个生成阶段审阅、修改、确认后继续。

首屏只突出这一条路径。示例、流程说明和匿名数据提示为它提供信任，不与主动作竞争。

## 3. Design Direction

- **Color strategy:** Restrained。未装订纸与铅字墨构成主要界面，校订朱砂的可见面积保持在每屏 8% 以内。
- **Theme scene:** 一位短剧创作者在有自然光的工作桌前整理零散素材，希望在安静、清晰且不会打断思路的界面中得到一份可继续修改的剧本。
- **Anchor references:** Sitor 负责首页留白和核心输入层级；Arc Studio 负责长时间写作的专注感；Fountain 剧本格式负责场景、动作和对白的语义结构。
- **Creative North Star:** 未装订的剧本。
- **Motion:** 仅用于状态反馈，普通过渡为 150–220ms，并完整支持减少动态设置。

首页可以使用 Playfair Display 与中文宋体表达编辑出版感；进入工作台后，导航、按钮、字段和状态统一使用 Inter 与中文无衬线。等宽字体只服务于场次、时长、版本和生成阶段。

## 4. Scope

- **Fidelity:** 低保真线框，确定信息层级、流程和状态，不决定最终像素细节。
- **Breadth:** 覆盖完整 V1 匿名访客流程，重点细化首页、创作设置、阶段工作台和导出。
- **Interactivity:** 描述完整交互模型和状态转换，不制作可点击原型。
- **Responsive:** 同时定义桌面与移动端结构。
- **Accessibility:** 以 WCAG 2.2 AA 为约束，覆盖键盘、焦点、对比度、状态表达和减少动态。
- **Technical constraints:** React 单页应用、NestJS API、PostgreSQL；生成任务需要支持断线恢复与阶段重试。
- **Out of scope:** 登录、付费、团队协作、商业广告分镜、视频生成、社区和模板市场。

### 5.5 Stage Review Pattern

六个阶段共用同一个审阅模型：

~~~text
生成中
  ↓
结构化产物出现
  ↓
用户直接编辑，或对单项执行局部重生成
  ↓
自动保存
  ↓
用户明确点击“确认并生成下一阶段”
~~~

每个阶段的主要内容：

| 阶段 | 典型范围 | 核心编辑形式 | 下一步按钮 |
|---|---:|---|---|
| 故事内核 | 前提 1 条、梗概 1 条、命题 1 条 | 大段文本字段 | 确认并生成人物 |
| 人物 | 3–8 人 | 人物列表 + 单人编辑面板 | 确认并生成空间 |
| 空间 | 3–8 个地点 | 地点列表 + 氛围与视觉母题 | 确认并生成节拍 |
| 情节节拍 | 8–15 个节拍 | 三幕时间线，可排序 | 确认并生成分场 |
| 分场 | 3–24 场 | 场景列表 + 场景摘要编辑 | 确认并生成剧本 |
| 完整剧本 | 约 3–20 分钟 | 剧本编辑器与场景导航 | 导出剧本 |

局部重生成始终针对一个明确对象，例如“重写人物弧光”或“重写第 04 场”，不提供开放式聊天框。

## 6. Key States

| 状态 | 用户需要看到 | 主要动作 |
|---|---|---|
| 首次访问 | 一句话输入、一次真实生成额度、完整示例 | 输入创意或查看示例 |
| 返回访问 | 尚未过期的匿名项目、剩余额度、过期时间 | 继续项目 |
| 空项目 | 当前阶段的目的与示例，不显示空白容器 | 开始生成故事内核 |
| 人机验证 | 为什么需要验证、预计耗时 | 完成验证 |
| 生成中 | 当前阶段、真实进度、已完成内容、后台继续提示 | 查看已完成阶段 |
| 等待确认 | 可编辑产物、保存状态、局部重生成、下一步后果 | 确认并继续 |
| 保存成功 | 时间戳和非颜色状态提示 | 继续编辑 |
| 局部生成失败 | 失败对象、原因摘要、原内容仍保留 | 重试该对象 |
| 流水线中断 | 已保留阶段、重新连接状态 | 恢复生成 |
| 今日额度已用完 | 下次重置时间、完整示例入口 | 查看或编辑现有项目 |
| 项目达到 5 个 | 哪个项目最早过期、删除后果 | 删除项目或取消新建 |
| 项目即将过期 | 明确日期、导出提醒 | 导出或继续编辑 |
| 项目已过期 | 数据无法恢复说明 | 建立新项目 |
| 输入过短或过长 | 当前长度、允许范围、修改建议 | 返回修改 |
| 导出中 | 目标格式与进度 | 等待或取消 |
| 导出失败 | 剧本仍安全、失败原因摘要 | 重试导出 |
| 离线 | 本地可编辑范围、生成不可用 | 重新连接 |

所有错误都在发生位置附近解释，页面级错误才使用顶部通知。不可逆删除使用标准确认对话框；普通创建和编辑不使用弹窗。

## 7. Interaction Model

### Entry

1. 用户打开首页，核心输入自动获得视觉优先级，但不自动抢夺键盘焦点。
2. 用户选择原创或改编，输入内容并提交。
3. 输入框在原位置展开设置，保留已输入内容。
4. 用户完成设置，系统检查每日额度并触发人机验证。
5. 验证通过后建立匿名项目并进入故事内核阶段。

### Stage Work

1. 后台任务生成当前阶段。
2. 页面以骨架和文字状态展示真实进度。
3. 产物完成后进入“等待确认”。
4. 用户可以直接编辑、撤销最近编辑，或对单个对象局部重生成。
5. 所有编辑自动保存，并显示明确时间。
6. 用户确认后锁定该版本并生成下一阶段。
7. 已确认阶段仍可返回编辑；若修改会影响后续内容，系统先解释影响范围，再创建新版本，不直接覆盖。

### Navigation

- 点击阶段可以查看已完成内容。
- 未生成阶段保持可见但不可进入，并说明解锁条件。
- 项目切换保留当前阶段、滚动位置和未提交字段。
- 浏览器后退返回上一个有意义的页面或阶段，不退出整个应用。
- 键盘用户可以跳过导航，直接进入主编辑区。

### Feedback

- 保存反馈出现在编辑区工具条，不使用全局 Toast 代替持续状态。
- 局部重生成在原对象中显示状态，不锁住整个页面。
- 下一阶段开始后，当前阶段仍可只读查看。
- 删除、过期和影响下游内容的操作必须说明后果。

## 8. Content Requirements

### Landing Copy

- 主标题：一句话，写成一部短剧。
- 说明：先确认故事、人物和分场，再得到一份可以继续修改的中文短剧初稿。
- 原创占位：例如：失眠的地铁维修工收到七年前事故现场的求救广播
- 改编占位：粘贴故事梗概或章节，系统会先提取人物、冲突和可改编情节
- 示例入口：查看一份完整示例
- 额度提示：今日可真实生成 1 次
- 保存提示：无需登录，匿名项目保留 7 天

### Stage Actions

- 编辑内容
- 重写这一项
- 撤销修改
- 确认并生成人物
- 确认并生成空间
- 确认并生成节拍
- 确认并生成分场
- 确认并生成完整剧本

### Trust and Safety

- AI 生成内容可能包含不准确或相似表达，请在发布或拍摄前人工审阅。
- 匿名项目使用当前浏览器标识，7 天后自动删除。
- 请勿提交身份证号、联系方式或未获授权的完整作品。
- 网文改编入口需要用户确认：我拥有该素材的使用权，或该素材允许我进行改编。

### Realistic Data Ranges

- 原创创意：10–1,000 个字符
- 改编素材：200–10,000 个中文字符
- 项目名称：1–80 个字符
- 气质与语调：2–80 个字符
- 匿名项目：0–5 个，加 1 个固定示例
- 人物：3–8 个
- 地点：3–8 个
- 节拍：8–15 个
- 场景：3–24 场
- 目标时长：3、5、8、12、20 分钟

V1 不依赖照片、插画或生成式图片。真实视觉内容来自文字、场次结构、进度和剧本稿纸，图标使用现有 Lucide 系统。
