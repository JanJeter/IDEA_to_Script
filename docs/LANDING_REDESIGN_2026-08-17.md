# 首页重构规划与实施记录

日期：2026-08-17
范围：首页视觉、首页创作入口、首页流程叙事与动效；不改动趋势页和工作台的业务流程。

## 1. 问题定义

旧首页的问题不是单一颜色或字号，而是太多“编辑出版感”的装饰同时抢占注意力：竖排英文、章节号、项目侧签、巨大细宋体、红色斜体、黑金样例、硬阴影和重复时间线。它们共同制造了模板化的 AI 设计感，并让真正的主任务“一句话开始写故事”退居次要位置。

同时，项目只加载了拉丁字体，中文依赖系统回退。不同设备上的中文字重和换行不可控，是正文发灰、标题偏薄的直接原因之一。

## 2. 重构目标

1. 首屏只保留一个明确任务：输入故事创意并继续。
2. 删除为了营造氛围而存在的装饰，让真实功能承担视觉表达。
3. 使用稳定的中文无衬线字体，正文不低于 500，控件不低于 600，标题使用 700–750。
4. 把参考视频的交互结构迁移进产品：首屏编排、正常滚动、中轴交替、一次性结尾动效。
5. 首页提交后原位展开项目设置，不再用二次弹窗打断上下文。
6. 桌面、平板和手机保持相同的信息顺序，不使用滚动劫持。

## 3. 视觉系统

### 字体

- 中文 UI：Noto Sans SC Variable。
- 标题：700–750。
- 按钮、标签、导航：600–700。
- 正文：500–550。
- 辅助信息：不小于 13px，字重不低于 500。
- 不在标题、按钮或标签中使用中文斜体与装饰性衬线体。

### 色彩

- 页面底色：`#f4f4f1`。
- 表面：`#ffffff`。
- 主文字：`#191918`。
- 正文：`#484844`。
- 次要文字：`#666660`。
- 分隔线：`#d2d2cc`。
- 单一强调色：`#b44738`。
- 成功状态：`#356a4d`。

规则：不使用渐变文字、纸张纹理、黑金主题或硬偏移阴影；普通容器只使用边框；强调色只用于主操作、焦点和当前阶段。

## 4. 信息架构

```text
简洁导航
└─ 产品名 / 创作过程 / 热点选题 / 完整示例 / 开始写故事

首屏
├─ 一句清楚的价值表达
├─ 原创 / 改编模式
├─ 故事输入
├─ 原位项目设置
└─ 示例与热点入口

创作过程
├─ 完整示例入口
├─ 01 故事内核
├─ 02 人物关系
├─ 03 场景空间
├─ 04 情节节拍
├─ 05 分场计划
└─ 06 完整剧本

热点说明
结尾行动
安全与人工审阅说明
```

旧首页的 Journey、Process 和项目侧签被合并为唯一的六阶段流程，避免重复解释同一件事。

## 5. 核心交互

### 首屏编排

- 导航直接出现。
- 产品说明：380ms。
- 主标题：480ms，延迟 170ms。
- 三段流程摘要：380ms，延迟 320ms。
- 输入器：460ms，延迟 450ms。
- 辅助入口：360ms，延迟 600ms。
- 缓动统一使用 `cubic-bezier(.16, 1, .3, 1)`。

导航随页面正常滚走，不做 sticky；页面不使用 scroll-snap、视差或滚动劫持。

### 原位项目设置

1. 首次提交只验证故事创意或改编素材。
2. 验证通过后，在同一个表单内展开项目名称、类型、目标时长和气质语调。
3. 焦点进入项目名称；返回修改时保留所有已填内容。
4. 设置展开后，Enter 与最终按钮都执行同一套创建逻辑。
5. API 错误显示在提交区域，内容不丢失。
6. 创建中暴露 `aria-busy` 并阻止重复提交。

保留的规则：原创 10–1,000 字；改编 200–10,000 字；改编必须确认素材使用权。

### 六阶段滚动叙事

- 使用正常文档流和一条 1px 中轴。
- 桌面端文案与真实 UI 片段左右交替。
- 每步占视口高度的约 78%，进入有效区间后只触发一次。
- 整个演示片段使用 430ms 的低位移进入。
- 内部内容使用 90ms 间隔的轻微位移，不通过透明度制造“正在生成”的闪烁。
- 数字只用于真实的六阶段顺序，不再作为装饰章节号。

### 结尾

- 只保留一次签名动效：黑、灰、朱砂色的剧本碎片向两侧释放。
- 粒子不响应指针，不使用彩虹庆祝效果。
- 移动端关闭碎片动效；减少动态效果模式下直接显示最终内容。

## 6. 响应式

- `> 1050px`：完整导航、双列中轴流程、最大内容宽度 1160px。
- `901–1050px`：保留完整导航，缩小流程列间距。
- `761–900px`：导航收为产品名和主操作，正文仍保持桌面阅读字号。
- `≤ 760px`：首屏左对齐；表单与设置单列；流程改为文案在上、演示在下；中轴移到左侧。
- `≤ 420px`：保持 16px 页面边距、16px 输入字号和至少 44px 触控目标。

手机端不隐藏真实功能：示例和热点入口仍保留在首屏输入下方。

## 7. 无障碍与性能约束

- 默认内容始终可见；IntersectionObserver 不可用时不产生空白区块。
- 所有输入都有标签、错误关联、错误焦点和键盘提交路径。
- 展开按钮暴露 `aria-expanded`，表单暴露 `aria-busy`。
- `prefers-reduced-motion: reduce` 下取消阶段与碎片动画。
- 动效只修改 transform、opacity 或 clip-path，不在 scroll 事件中同步读写布局。
- 中文变量字体实测整页请求约 1.1MB；本轮选择字重和跨设备一致性优先。后续若以弱网 LCP 为第一目标，应对首页字符做字体子集，而不是回退到不可控的系统字体。

## 8. 实施文件

- `apps/web/src/components/LandingPage.tsx`：页面结构、内联建档、观察器和六阶段内容。
- `apps/web/src/components/LandingPage.css`：视觉令牌、排版、动效和响应式。
- `apps/web/src/App.tsx`：首页直接创建项目，保留趋势页与工作台的创建弹窗。
- `apps/web/src/main.tsx`：加载中文变量字体。
- `apps/web/src/components/LandingPage.test.tsx`：首页交互、错误、焦点、观察器和样式契约。
- `apps/web/index.html`：页面标题、描述与主题色。
